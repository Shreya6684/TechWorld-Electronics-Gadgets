# TechWorld – Electronics & Gadgets

A modern, responsive electronics and gadgets e-commerce website built using HTML5, CSS3, and vanilla JavaScript. This project was developed for the **Data Alcott Systems Free Web Development Internship**, under Task ID **WD-EC-003**.

## 🚀 Project Overview

TechWorld is a frontend e-commerce website concept designed to provide users with a convenient way to explore electronic products, view product specifications, manage a shopping cart, save favourites, and complete a simulated checkout process.

The website features a clean layout, a technology-inspired colour palette, responsive product cards, and interactive shopping functionality.

## ✨ Features

- Responsive homepage with a hero section
- Product categories and featured products
- Product search functionality
- Category and brand filters
- Price range and rating filters
- Product sorting by price and rating
- Individual product detail pages
- Product specifications and stock indicators
- Add-to-cart functionality
- Quantity adjustment and item removal
- Automatic subtotal, shipping, and total calculation
- Simulated checkout with shipping details
- Demo login and registration
- User profile and order history
- Saved addresses and wishlist
- About Us page
- Contact Us page
- Newsletter form demonstration
- Mobile-friendly navigation
- Local Storage for demo data persistence

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, layouts, and responsive design
- **JavaScript** – Product rendering and interactive functionality
- **Local Storage** – Saving cart items, wishlist, demo accounts, and orders in the browser
- **Google Fonts** – Typography
- **Unsplash** – External product imagery

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Navigate through the website and test the shopping features.

An internet connection is required for externally hosted images and fonts.

## 🎨 Design Guidelines

The website follows a modern, technology-focused visual style.

- Dark Blue: `#0A2647`
- White: `#FFFFFF`
- Tech Blue: `#00B4D8`

The layout is designed to work across desktop, tablet, and mobile screen sizes.

## 🧪 Testing

## ⚠️ Limitations

This is a frontend-only educational project. It does not use a backend server or database. Authentication is simulated using browser Local Storage and is not secure for real users. Checkout does not process real payments, and contact and newsletter forms do not send information to a real service.

Product information and prices are sample data and should be verified before any real-world use.
